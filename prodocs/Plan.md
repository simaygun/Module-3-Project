# Geliştirme Planı (Plan.md) - SubCentral v1.0

Bu plan, PRD ve MVP kapsamında tanımlanan kullanıcı hikayelerinin teknik adımlara bölünmüş halidir.

## 🛠️ Planlanan Teknik Adımlar
- [x] **Adım 1:** Streamlit ile Frontend arayüzünün tasarlanması (Popüler şablonların eklenmesi, Pasta grafik görselleştirmesi).
- [x] **Adım 2:** FastAPI projesinin ayağa kaldırılması, CORS ayarlarının yapılması ve `/subscriptions` CRUD endpoint altyapısının kurgulanması.
- [ ] **Adım 3:** Yerel veri tabanı (SQLite) entegrasyonunun tamamlanması.
- [ ] **Adım 4:** Core Yapay Zeka (Gemini API) entegrasyonunun backend'e taşınması ve kullanıcıya canlı bütçe raporu sunulması.
